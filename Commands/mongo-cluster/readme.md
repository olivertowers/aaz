# [Group] _mongo-cluster_

Manage Mongo cluster resources.

## Subgroups

- [firewall-rule](/Commands/mongo-cluster/firewall-rule/readme.md)
: Manage Firewall Rule

- [replica](/Commands/mongo-cluster/replica/readme.md)
: Manage Mongo cluster replicas.

## Commands

- [create](/Commands/mongo-cluster/_create.md)
: Create a mongo cluster. Update overwrites all properties for the resource. To only modify some of the properties, use PATCH.

- [delete](/Commands/mongo-cluster/_delete.md)
: Delete a mongo cluster.

- [list](/Commands/mongo-cluster/_list.md)
: List all the mongo clusters in a given resource group.

- [promote](/Commands/mongo-cluster/_promote.md)
: Promotes a replica mongo cluster to a primary role.

- [show](/Commands/mongo-cluster/_show.md)
: Get information about a mongo cluster.

- [update](/Commands/mongo-cluster/_update.md)
: Update a mongo cluster resource.
